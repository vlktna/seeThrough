# SeeThrough

**Indoor understanding for robots, contributed by people.**

SeeThrough enables indoor coordination between robots, between people, or across both. Our MVP is an Android app that
uses existing Wi-Fi signals to estimate a person’s room and share it on a live map. The same software can be adapted to
run directly on Wi-Fi-enabled robots, helping participants locate one another, coordinate tasks, and request assistance.

Try the [SeeThrough live demo](https://seethrough-live.v-volokitinaa.chatgpt.site/). The [Android App](https://github.com/Willboydie/See-Through)

### Short description of the technology used

SeeThrough uses **Wi-Fi fingerprints**, patterns of signal strength from nearby access points—to estimate which room a
device is in. Our Android app compares live readings with patterns recorded in known rooms and updates a shared map. It
works with existing Wi-Fi infrastructure, without GPS or additional beacons.
